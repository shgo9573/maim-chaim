# מים חיים – חוקר תורני (MCP)

זהו רכיב נפרד עבור מאגר אוצריא. הוא אינו משתנה בקוד האתר הראשי ואינו מופעל על ידי תהליך הבנייה של הפרונט.

## מבנה

- `server/` — שרת MCP לקריאה בלבד, עם כלי חיפוש, שליפת תוכן, מפרשים, תוכן עניינים ובדיקת חיבור.
- `plugin/` — מניפסט התוסף, כתובת MCP והנחיות המחקר.

## סטטוס

הקוד עבר בדיקת תחביר Node.js וארבע בדיקות יחידה. בדיקות אלו אינן פונות לשרת החי. עדיין נדרשת פריסה לשרת אוצריא ואימות מקצה לקצה של `check_otzaria_connection` ושל חיפוש אמיתי לפני שמצהירים שהשילוב פעיל.

## בטיחות והפרדה

- כל כלי ה-MCP לקריאה בלבד.
- אין לשנות או להחליף את תצורת Nginx הקיימת; יש להוסיף את `server/nginx-location.conf` בתוך בלוק HTTPS הקיים לאחר גיבוי ובדיקה.
- יש להגדיר את `OTZARIA_UID` בקובץ `server/.env` המקומי על השרת. הערך שסיפק בעל האתר אינו נשמר ב-Git.
- הנתיב הציבורי `/mcp` יהיה פעיל רק לאחר שהשירות יותקן ו-Nginx יוגדר בהתאם.
- תהליך GitHub Actions הקיים deploys only when `main` changes. הוספת התיקייה לענף זה אינה פורסת את שירות ה-MCP באופן אוטומטי.

## בדיקה מקומית

```bash
cd integrations/mayim-chaim-mcp/server
node --check src/server.js
npm test
```

## פריסה

פעל לפי `server/README.md`. אל תעתיק את כל `nginx-location.conf` במקום קובץ Nginx הקיים; הוסף את שני ה-location בלבד לתוך בלוק HTTPS המתאים, לאחר גיבוי. הרץ `nginx -t` לפני reload.
