# שילוב HTML ניסיוני בצורת הדף של מים חיים

השחזור הועתק לתוך המאגר הזה: `src/vilna-html/template.html` ו־`src/vilna-html/tractates.json`. בזמן `npm run build` נבנה `public/vilna-html/index.html` ונעתקים קובצי PDF.js אל `public/vilna-html/vendor/`. בזמן שימוש אין תלות בשרת Next.js של `vilna-html`, ב־GitHub, או ב־CDN של PDF.js.

## שימוש

בכפתור `צורת הדף ניסיוני` פותחים את התצוגה המקומית. כפתור HTML ניסיוני מחליף את ה־PDF בתצוגת HTML. המערכת מעבירה ל־HTML את אותן מלבני בועות שזוהו ב־PDF ומחזירה את בחירת הבועה לחלונית המפרשים הקיימת.

## מקור HTML חיצוני — כבוי כברירת מחדל

באזור הניהול יש לשונית `ניסיוניים` ומתג `אפשר הורדת HTML ניסיוני מ־SHAS / HebrewBooks`. כשהמתג כבוי, הבחירה המקומית היא האפשרות היחידה. כשהוא פעיל, במצב HTML מופיעה בחירת מקור:

- `הקובץ המקומי` — ברירת מחדל, מתוך PDF המסכת שכבר נמצאים בשרת.
- `SHAS.org` — קובץ ה־PDF לדף דרך הנתיב הקיים `/api/shas/daf`.
- `HebrewBooks לפי סדר הדפים` — מורידים את כרך HebrewBooks לפי `req` שכבר מוגדר במיפוי המסכתות ושומרים את הדף המתאים במטמון.

ה־PDF שנבחר נשלח גם ל־PDF.js לצורך יצירת HTML וגם ל־PDF.js בצד צורת הדף לצורך הפקת הבועות. כך שניהם עובדים על אותו קובץ ומערכת המפרשים נשארת זו של מים חיים. כאשר נבחר מקור חיצוני, מופיע גם כפתור `הורדת HTML ניסיוני`; הקובץ שיורד כולל את הגופנים שנשלפו מה־PDF ואת שכבת הבועות.

ההגדרה נשמרת בקובץ מחוץ ל־Git: `/var/data/otzaria/site-feature-settings.json` (או `data/site-feature-settings.json` בסביבת פיתוח). אם הקובץ לא קיים, המקור החיצוני כבוי.

## בדיקות

יש לבדוק לאחר המיזוג בפועל לפחות דף אחד מ־SHAS ודף אחד מ־HebrewBooks: שה־PDF נטען, שה־HTML תואם את עימוד אותו מקור, שהבועות הצפות פותחות את חלונית המפרשים, ושקובץ HTML שהורד נפתח גם ללא השרת.
